# Bimanual-Franka-Planning

A planning library for a bimanual Franka FR3 system. Provides inverse kinematics (TRAC-IK and Pink), motion planning (OMPL + VAMP), and collision-aware planning through a unified Python interface — mirroring the structure and API of [Autolife-Planning](https://github.com/AdaCompNUS/Autolife-Planning).
